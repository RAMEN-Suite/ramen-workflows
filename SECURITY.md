# Security policy

## Supported versions

Security fixes are released as a new version. Older versions are not patched; update to the latest release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for an undisclosed vulnerability.

Include the affected version, the affected workflow or action, reproduction steps, impact, and any known mitigation. You can expect an acknowledgement within seven days. A fix timeline depends on severity and reproducibility; coordinated disclosure will be agreed with the reporter before details are published.

## Supply chain

Every action used here is pinned to a full commit SHA and every container image to a digest; Renovate updates them.

Releases are immutable: once published, a version's tag can't be moved or deleted. Pin this repository by the commit SHA of a release (see [README](README.md#usage)).
